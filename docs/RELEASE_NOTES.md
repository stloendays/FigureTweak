FigureTweak 论文调图 — 下载 `FigureTweak.exe`，双击运行，或把论文的图文件夹拖到它上面。

**1.2 新增**
- 默认样式：图例文字默认加粗；文字的白色描边和无边线的白底框默认去掉（在有底色的阅读器里不再显示成白块，也不再遮断框线），有边线的标签框保留；编辑器里的手工设置仍然优先
- 整图「文字外框：去掉」现在连无边线的白底一起去掉（单个标注的「外框：无」仍只留白底）
- 已接入论文的 tweak.py 在「接入新论文」时升级到 1.2

**1.1 新增**
- 有框线 / 无框线 / 无轴线：每个图表单独设，或在画布里对整张图设，一键用到全稿所有图；带框标注可去掉边框只留白底
- Origin 式坐标轴设置：起止范围、线性/对数、主刻度间隔、次刻度、刻度朝向、网格线
- 参考线（数据坐标，可带标注）、图例边框与九宫格位置、鼠标处数据坐标读数
- 旧论文的 tweak.py 在「接入新论文」时自动升级，重新出图逐像素核对

**1.0**
- 论文列表：自动扫描电脑上可编辑的论文图，按论文 / 版本（git worktree）分组，带缩略图、搜索、改名
- 一键接入新论文：给 `Page.save` 加上 `tweak.apply`，重新出图并逐像素比对原图，生成图号表
- 图层编辑器：移动、改写、改字号、换色、插入箭头 / 括号 / 文字，全稿字号一致性检查

出图使用你自己装有 matplotlib 的 Python。
