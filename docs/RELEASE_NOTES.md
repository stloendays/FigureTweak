**1.3 新增**
- 图表模板从 16 种增加到 43 种，参考 Hiplot 的图库，新增：堆叠面积/河流图、环形图/饼图、雷达图、山脊图、云雨图、密度曲线、气泡图、相关性热图、双 Y 轴图、帕累托图、正负偏差条形图、玫瑰图/环形柱状图、等高线图、矩形树图、华夫饼图、韦恩图、UpSet 交集图、桑基图、三元相图、主成分分析（PCA）、平行坐标图、多期名次变化图、背靠背条形图、火山图、矩阵气泡图、Q-Q 图、区间条形图；筛选新增“多变量”“集合与交集”
- 「数据」：读出任何图表里画出的数值（柱、线、点、误差棒、热图矩阵），在表格里改，可从 Excel 直接粘贴；改动记在调整文件里，脚本和原始数据不动，随时一键恢复
- 「添加系列」：在已有图表上加柱、折线、散点或面积，可带误差棒；加的柱子可与原有柱子并排（原有柱子和它们的误差棒自动让位），横向条形图同样适用；名称自动加入图例
- 模板做的图：直接改源数据表（加行加列、改列名），在「图表设置」里改列的对应、选项、尺寸和图内标题，或整张图换成别的图表类型
- 脚本读外部数据文件的图：列出这些文件，一键用 Excel 打开，改完按新数据重新出图
- 已接入论文的 tweak.py 在「接入新论文」时升级到 1.3

**1.2 新增**

- 已接入论文的 tweak.py 在「接入新论文」时升级到 1.2
