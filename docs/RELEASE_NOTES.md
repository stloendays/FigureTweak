**1.7 界面与稳定性**
- 顶栏重排：保存、放弃修改、全部还原固定在右上角，窄屏下插入按钮只显示图标（悬停看名字）；缩放和状态移到第二行。「适应」把整张图放进窗口，窗口变大变小时跟着缩放；Ctrl+滚轮以鼠标处为中心缩放
- 新增快捷键：Ctrl+A 全选（选中图表里的对象时只选这个图表）、Ctrl+D 复制插入的文字和形状、Ctrl+0 适应窗口、Ctrl+= / Ctrl+− 缩放画面、拖动中按 Esc 取消；顶栏「?」或按 ? / F1 看全部快捷键
- 图层列表：柱子按类别命名（如 Fe、Ru），共用一个分图字母的图表编号为 a-1、a-2 并附上标题，色标单独标出；热图色标的几百种颜色折叠在「全部 N 种」后面
- 改文字时边打边预览；保存后仍能撤销；单击对象不再清掉重做记录，手抖的单击不算拖动；细线周围留几像素也能点中
- 修复：出图期间的改动会在出图结束后丢掉（现在出图时画布锁定）；在数据、插入图表、图表设置里保存时画布上未保存的调整会丢掉（现在一起保存）；坐标轴的线性/对数、次刻度、刻度朝向、网格在已保存过的图上点回原设置会失效；刻度标签原本有旋转时旋转预览不对；放大左对齐文字时预览以中心缩放、出图后位置跳动；刻度和图例的斜体不生效；撤销插入后留下空的图层
- 修复：调图程序出错或已关闭时保存按钮永久变灰；脚本里留有 plt.show() 时出图卡死（现在用无窗口后端并限时）；中文日志乱码；两个窗口开着不同的图时保存写错图（现在拒绝并提示刷新）；重复打开时两个程序抢同一端口
- 安全：其他网站不能向调图程序发请求；「全部还原」前把调整备份为 .tweaks.json.bak
- 对话框里有没应用的修改时，点外面或按 Esc 会先确认；删除添加的系列或插入的图表前会确认；Alt+滚轮放大所选对象（普通滚轮只滚动页面）

**1.6 新增与修复（适配任何人或 agent 写的作图脚本）**
- 出图不会再因为某一条调整失败：tweak.py 用不上的那一步会跳过，并在出图日志和状态栏里写明“N 处调整没能用上”，其余调整照常生效
- constrained / tight 布局的图：出图时固定一次版面。以前改了字号或刻度后整张图重新排版，图表位置一变，所有调整都对不上对象；拖动过的图表在保存时也会弹回原处
- 子图（subfigures）里的标题、文字和图例现在可以编辑
- 修复：误差棒的横坐标是文字类别时，整张图出不来；给柱、框、扇形等设虚线时出错
- 记录出图脚本时用实际运行的脚本文件（runpy 或包装脚本下也对）
- 新增自检：`python tweak.py --check <图文件夹> <图名> --rerun`，查出文字被存成路径、SVG 被裁边、脚本指向别的工作区、两次出图不一致（随机数没设种子）、系列没有名字等，每条都给出改法
- 用一套覆盖 30 多种画法的测试图（柱、误差棒、带、色条、等高线、对数轴、双轴、箱线、小提琴、极坐标、3D、饼图、内嵌图、表格、子图、pandas 画图等）给每个对象加上编辑器能做的全部调整，全部生效、对象的键前后一致

**1.5 新增与修复**
- 右键菜单：在对象上右键可改颜色（含“本图表同色一起改”）、线型、线宽、不透明度、字号、加粗，换图表风格（期刊风 / Origin 风 / 网格风 / 极简），开关网格，查看数据、添加系列，选中图表里同类的全部对象，复制 / 粘贴样式，还原、隐藏、删除；在空白处右键可在点击位置插入文字、箭头、框、图表，或一键换全图风格；多选后右键可一起改、一起对齐。图层列表里也能右键。双击文字直接编辑
- 修复：从另一个 git worktree 复制来的图，保存后重新出图的是另一个工作区的脚本，当前这份的图一直不变（看起来像网格、框线去不掉）。现在总是用图所在工作区里的脚本出图
- 修复：给没有边线的色带设虚线会让整张图出图失败；这类对象现在不显示线型选项，已有的设置也不再报错
- Delete 键：插入的文字和形状、添加的系列、插入的图表直接删除，其余对象隐藏

**1.4 新增与修复**
- 在已有的图里插入新图表：顶栏「插入 → 图表」，从 43 种模板里选类型、粘贴数据、对应列、填位置和大小，就画进这张图；插入的图表和别的图表一样能拖动、换色、改字号，选中后在「插入的图表」里改数据、设置、位置或删除。脚本不动，插入的图表存在图旁边的 `<图名>_charts/` 里
- 换色可以“本图表同色一起改”（默认）或“全图同色一起改”：同一条曲线的线、误差带、点和图例标记一起变，不再只变一根线
- 多选后可以一起改颜色、线宽、不透明度和线型
- 网格线开关即时预览；画布里新增整图「网格线：全去掉 / 横线 / 竖线 / 全部」，并可一键用到全稿所有图
- 论文的 tweak.py 比编辑器旧时，画布面板提示并可一键升级（逐像素核对）
